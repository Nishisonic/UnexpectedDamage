## 主な変更

- Java 8とJava 25の両方で動作するよう、NashornからJavaの配列・コレクション・JSON値を扱う処理を修正しました。
- 潜水艦隊攻撃（攻撃種別300～302）の火力計算に対応しました。
- 潜水艦による対地攻撃の加算補正を修正しました。
- 特殊アイテムによるステータスボーナスを火力計算へ反映しました。
- 以下を含む装備ボーナスを追加・更新しました。
  - 烈風 一一型
  - Ju87 D-4(Fliegerass)
  - Bf109 T-3(G)
  - 12.7cm単装高角砲改三
  - F4U-7
  - SB2U-2
  - 震電改二(艦戦型改二)
  - 震電改三(試製 噴式震電)
  - 三式爆雷投射機改
  - 流星改(友永隊)

## 不具合修正

- 表示装備IDが正しく数値化されず、装備取得時に `null` となる問題を修正しました。
- Java 25環境でJavaオブジェクトが文字列・配列・真偽値として誤って解釈される問題を修正しました。
- 連合艦隊、ダメコン、弾薬量、触接・特殊攻撃補正などの計算時に発生する互換性エラーを修正しました。
- JST日時の生成に `Asia/Tokyo` を使用するよう修正しました。
