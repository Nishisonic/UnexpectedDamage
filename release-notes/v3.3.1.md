# 注意事項
* v1.2.6より過去イベントは検知しません。2期の海域(6-2と7-1を除く)と現イベント海域のみ検知します
* 熟練度は不明な要素が多いため、ズレがよく発生しますが仕様です
* 夜襲でも機数の減少により、誤検知することがあります
  * [【赤仮】航海日誌拡張版](https://github.com/noratako5/logbook)であれば、この誤検知はありません
* v1.6.2より、洋上補給に擬似対応しました
  * **注意点**
    * ボスで洋上補給を使わなかったとしても、使ったという形で処理を行います
    * 母港内の弾薬量が足りず、十分に補給出来なかったとしてもX%分補給したものとして扱います
* エラーで拡張版が落ち、script.logに` org.eclipse.swt.SWTException: Failed to execute runnable (java.util.ConcurrentModificationException) `が書かれていた場合について
  * 【応急処置】ドロップ報告書にデータが表示されるまで艦これのデータを読み込まない
    * 読み込み関連のバグなので、他にデータを読み込ませなければエラーを防げます
  * 他の対処法
    * [航海日誌拡張版2.5.7.x](https://github.com/Nishisonic/logbook/releases)を使う
    * [【赤仮】航海日誌拡張版](https://github.com/noratako5/logbook)の2.4.9.44.81以降を使う

## 自動アップデート機能の手順について
1. 各ファイルを入れた状態で拡張版を起動する
2. 自動アップデートが発動(何も触らない)
3. **ファイルが変わったのを確認したら拡張版を再起動する(ここ重要)**

※ファイルが変わっただけでは拡張版に読み込まれませんので注意してください。
